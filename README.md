# 🎵 MusicPulse - 全球音乐趋势看板

实时追踪 **13个音乐平台** 的热门趋势，覆盖海外+国内主流音乐平台。

## 🌍 平台覆盖

**海外 (7)**：Spotify · Apple Music · Deezer · YouTube Music · TikTok · KKBOX · Last.fm

**国内 (6)**：网易云音乐 · QQ音乐 · 酷狗音乐 · 酷我音乐 · 抖音 · 汽水音乐

## 🔗 在线访问

👉 [点击打开 MusicPulse](https://salasamanra.github.io/music-pulse/)

## ✨ 特性

- 🟢 **实时数据**：12个平台已接入真实API
- 🌐 **跨平台对比**：查看哪些歌曲同时在多个平台上榜
- 📊 **趋势图表**：每日热度变化可视化
- 🎯 **状态标识**：绿色=LIVE实时数据，红色=MOCK示例数据

## 🛠 技术栈

React + TypeScript + Vite，打包为单个 HTML 文件，零依赖部署。
